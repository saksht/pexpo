# Pexpo

Personal offensive-security portfolio — HackTheBox writeups, tools, and exploit breakdowns.

**Live site:** https://saksht.github.io/pexpo/

## About

A single-page portfolio built by Akshat Singh (AppSec / Penetration Tester). It features animated navigation, a dark/light theme toggle, an embedded résumé, and a built-in reader for machine writeups.

## Deployment

The entire site is a single self-contained file: `index.html`. Everything (styles, scripts, writeups, and the résumé PDF) is inlined, so there are no external dependencies.

Hosted on **GitHub Pages** — Settings → Pages → Deploy from a branch → `main` / root.

To update the live site, replace `index.html` and commit.
